# Manual interno: DOMino Inmobiliaria (para Claudio)

## Qué es
DOMino Inmobiliaria es un sitio web para inmobiliarias, de The DOM Studio Web. Sirve para captar propietarios que quieren vender o alquilar, y para mostrar propiedades a quienes quieren comprar o invertir. La versión actual es una demostración con datos de ejemplo.

## Qué ve un visitante
1. **Portada:** una frase principal y tres botones: "Quiero comprar", "Quiero vender" y "Busco invertir". Cada uno lleva a su sección.
2. **Solicitar valuación gratuita (para propietarios):** un formulario con nombre completo, tipo de inmueble (casa, departamento, lote o terreno, local u oficina), zona y teléfono. Al tocar "Analizar mi propiedad", si falta algo avisa qué completar; si está todo, abre WhatsApp con el mensaje ya escrito con esos datos. La persona solo tiene que enviarlo.
3. **Cómo trabajamos:** tres pasos: análisis, estrategia y cierre.
4. **Propiedades destacadas:** tarjetas con foto, precio, zona y características. Cada una tiene un botón "Consultar por WhatsApp" que abre el chat con un mensaje que nombra la propiedad.
5. **Corredor responsable, portal y contacto:** datos legales de la inmobiliaria, un botón "Acceso agentes" que lleva al portal de gestión, y los datos de contacto.

## Cómo se personaliza
Para cada inmobiliaria se cambian: el nombre, el número de WhatsApp, las propiedades con sus fotos y precios, los datos del corredor responsable y el contacto, y el logo. Lo hace The DOM Studio Web. La firma de The DOM se mantiene al pie.

## Qué NO hace todavía
- No guarda las consultas en ningún lugar: llegan solo por WhatsApp.
- No tiene panel para cargar propiedades: se editan en el código.
- El "Acceso agentes" lleva a un portal aparte; este sitio no tiene inicio de sesión.
